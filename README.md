# FinCore Agency Financial Management

A React + Vite financial management dashboard designed for a manpower/agency business.

## Included modules
- Dashboard
- Income / Revenue Management
- Expense Management
- Transactions / General Ledger
- Clients & Project Profitability
- Employees & Staff
- Payroll
- Budget Management
- Profit & Loss
- Cash Flow
- Financial Reports
- AI Financial Suggestions
- Settings

## Run locally

1. Install Node.js.
2. Open this project folder in a terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local Vite URL shown in the terminal.

## Notes
This version is a front-end prototype. Data is stored in React state and resets when the page is refreshed. For production, connect it to a backend such as PHP/MySQL, Node/Express, Laravel, or Supabase.
